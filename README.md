# Two-Factor Authentication (2FA)

## Project Description

This project implements a Two-Factor Authentication (2FA) system using password authentication and Time-Based One-Time Password (TOTP).

## Technologies

- Python
- Flask
- SQLite
- PyOTP
- QR Code
